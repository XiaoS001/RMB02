# 数据库设计 · RMB02

> 11 张表。SQLite（WAL 可选）。测试用 `sqlite:///:memory:` 注入，绝不碰业务库。

---

## 一、表清单

| 表 | 用途 | 关键约束 |
|---|---|---|
| `user` | 用户（4 档角色） | username 唯一 |
| `target` | 被测对象 | kind: http/offline · contract_source 记录契约来源 |
| `contract` | 接口契约 | path+method+fields_json+source+confidence |
| `eval_task` | 一次评测任务 | status: created/generated/... |
| `case` | 一条用例 | status: valid/invalid · invalid_layer/reason |
| `case_run` | 用例真跑结果 | status_code/response_body/passed/duration_ms |
| `model_output` | 被评测的模型输出 | run_index 占位 |
| `score` | 机器打分 | **必须带 run_index**（稳定性按遍比较）· hallucination 可空（N/A） |
| `annotation` | 人工标注 | 🔴 与 score **分表**（机器分不覆盖人工）· verdict: agree/doubt/reject |
| `settlement` | 按条结算 | 🔴 **UniqueConstraint(annotator_id, task_id)** —— 同一组合只结算一次 |
| `usage`（预留） | 平台用量 | — |

## 二、核心表结构

### `settlement`（🔴 唯一约束防重复付款）

```sql
CREATE TABLE settlement (
    id INTEGER PRIMARY KEY,
    annotator_id INTEGER NOT NULL REFERENCES user(id),
    task_id INTEGER NOT NULL REFERENCES eval_task(id),
    case_count INTEGER NOT NULL DEFAULT 0,
    unit_price FLOAT NOT NULL DEFAULT 0,
    amount FLOAT NOT NULL DEFAULT 0,
    created_at DATETIME NOT NULL,
    CONSTRAINT uq_settle_annotator_task UNIQUE (annotator_id, task_id)
);
```

**为什么唯一约束**（审查 Bug 1）：重复结算会多付一倍（钱的问题）。
业务层先查后拒 + 数据库约束兜底 —— 就算并发 bug 也插不进去。

### `score`（run_index 区分 3 遍稳定性）

```sql
CREATE TABLE score (
    id INTEGER PRIMARY KEY,
    model_output_id INTEGER NOT NULL REFERENCES model_output(id),
    accuracy FLOAT NOT NULL DEFAULT 0,
    relevance FLOAT NOT NULL DEFAULT 0,
    format FLOAT NOT NULL DEFAULT 0,
    hallucination FLOAT NULL,          -- NULL = N/A（无证据来源）
    total FLOAT NOT NULL DEFAULT 0,
    run_index INTEGER NOT NULL DEFAULT 0
);
```

**同一 model_output_id 应有 3 条不同 run_index（0/1/2）** —— 稳定性 n=5×3 的基础。

### `annotation`（分表，不覆盖机器分）

```sql
CREATE TABLE annotation (
    id INTEGER PRIMARY KEY,
    model_output_id INTEGER NOT NULL REFERENCES model_output(id),
    annotator_id INTEGER NOT NULL REFERENCES user(id),
    verdict VARCHAR(20) NOT NULL,      -- agree / doubt / reject
    note TEXT NULL,
    created_at DATETIME NOT NULL
);
```

## 三、关系

```
target 1—n contract
target 1—n eval_task 1—n case 1—n case_run
              eval_task 1—n model_output 1—n score
                               model_output 1—n annotation
user 1—n annotation · user 1—n settlement
```

- 测试用内存库，业务库 `data/rmb02.db` 被 `.gitignore` 排除，CI 断言不污染
- 结算唯一约束防重复付款（钱）
