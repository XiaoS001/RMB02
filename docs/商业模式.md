# 商业模式 · RMB02

> 🔴 与 RMB01 的变现逻辑**不同层**，必须写清区别（任务单 v2 第五节第 9 条）。

---

## 一、与 RMB01 的区别

| | RMB01 | RMB02 |
|---|---|---|
| 收费对象 | 用知识库的**企业自己** | **做 AI 产品的团队 / 需要评测报告的甲方** |
| 计费方式 | SaaS 订阅 + **按次扣额度**（客户自己用） | **按条报价 + 标注按条结算 + 平台抽成**（平台代客户验收交付物） |
| 成本结构 | 模型 token | **模型 token + 人工标注（主要变动成本）** |

**两者不同层**：RMB01 是"客户买工具自己用"，RMB02 是"平台代客户做验收交付物"。
不是同一个东西的两种叫法。

## 二、三条收入线

### 1. 评测任务按条报价（平台收入）

| 项 | 值 | 来源 |
|---|---|---|
| 单价（元/接口用例） | **1.0** | 示例值：按「1 条用例 ≈ 1 分钟人工核对 + 0.5 分钟模型调用」估算，见成本结构 |
| 平台抽成比例 | **20%** | 示例值：行业惯例 15~30%（对比：外包平台抽 10~20%），取中值 |

**怎么算**：一条评测任务 = 契约里每个接口生成 4 类用例（正常/边界/异常/authz），
按条计价。甲方按"有效用例数"付费（invalid 的不计费 —— 与统计口径一致）。

### 2. 标注按条结算（付给标注员）

| 项 | 值 | 来源 |
|---|---|---|
| 标注单价（元/条） | **0.5** | 示例值：低于评测单价（标注比用例生成简单），约为评测单价的 50% |

标注员收入 = 标注条数 × 0.5 元。平台抽成 = 评测收入 - 标注支出 - 模型成本。

### 3. （可选）报告增值服务

- 深度报告 / 竞品对比 / 持续监控订阅 —— 未实现，仅方向

## 三、成本结构（单条评测用例）

| 成本 | 估算 | 说明 |
|---|---|---|
| 模型 token | ~0.01 元/条 | 示例值：按 1 条用例 1 次模型调用、约 2K token、DeepSeek 级别价格估算 |
| 人工标注 | 0.5 元/条 | 主要变动成本（标注员结算） |
| 平台毛利 | 1.0 - 0.01 - 0.5 = **0.49 元/条** | 毛利率 ≈ 49%（示例值） |

> 🔴 **以上数字全是"示例值"**，用于说明成本结构怎么算、毛利率怎么来。
> 真实定价需按实际模型价格 + 标注效率标定。面试时如实说"这是示例估算"。

## 四、目标客户与获客路径

| 客户 | 痛点 | 获客路径 |
|---|---|---|
| AI 产品创业团队 | 说不清模型行不行，投资人要评测报告 | 技术社区（GitHub/HN）→ 试用报告 |
| 大厂 AI 中台 | 内部多模型选型要横向对比 | 标杆客户 → 案例 |
| 评测外包甲方 | 要交付物不要过程 | 平台抽成模式（对比外包平台） |

---

## 五、为什么"平台抽成"是卖点（区别外包标注）

外包标注平台抽 10~20% 但**不提供评测能力**；RMB02 的核心是**评测引擎**
（契约抽取 + 三层校验 + 四维打分）—— 标注只是其中一环。抽成买的不是"转手劳动力"，
是**评测方法论 + 一致性保障**（机器分 + 人工复核 + 一致率可审计）。
